## Requirement and final old-stack behavior

Intervening v02–v05 changed-path inventories contain no registry edits; their inspected XPU dispatch/platform additions contain no subprocess, hard-exit, finalizer, inspection, or registry-consumer references. The removed block exported no interface or persistent state; it ran only after successful serialization. Later released behavior already uses ordinary teardown, and no surviving local user relies on the bypass.
