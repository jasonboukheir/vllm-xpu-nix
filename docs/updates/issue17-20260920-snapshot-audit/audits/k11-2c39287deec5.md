## Requirement and correctness

The released Brutus/Arc Pro B70 D256/G128, Q24/KV4 profile combines packed
K4V2 history with resident rotated FP16 pages. k11 accelerates reading those
resident pages through existing Xe2 block-copy machinery. It changes neither
record format nor quantization, residency, softmax arithmetic or split order.
Its two-file delta adds `load_tail_k_fragment`, `load_tail_v_fragment` and
alignment-selected dispatch in
`csrc/xpu/attn/xe_2/collective/kvarn_decode_mainloop.hpp`, plus regression
coverage in `tests/flash_attn/test_kvarn_k4v2_xpu.py`.

The indexing is consistent with the existing scalar reader:

- Physical page lookup uses `logical_tile/2`; `block_to_slot` selects the
  resident slot. The record cursor refreshes at even tiles and odd split
  starts. `logical_tile&1` selects tokens 0–63 or 64–127 within that slot.
- K constructs a `(128,256)` surface, strides `(token_stride,1)`, and selects
  K64×D64 tiles with `dim_tile/64`. V constructs `(256,128)`, strides
  `(1,token_stride)`, and selects D32×K64 tiles with `value_tile/32`.
  `Base::TiledCopyK/V.get_slice(thread)` partitions the coordinates and
  `reorder(loaded,dst)` produces the existing MMA-B layout. This preserves
  subgroup/lane ownership through the same copy/MMA abstraction as ordinary
  attention, rather than assuming loaded register order equals MMA order.
- Binding validation in `kvarn_decode_xe2.cpp` requires contiguous half
  `[slots,128,4,256]` pools. Their byte width/pitch/height are 512/2048/128;
  head offsets are 512 bytes and slot offsets 262,144 bytes. These preserve
  64-byte alignment. SYCL-TLA `Xe2DTraitsBase` requires aligned bases and
  width/pitch multiples of four. Independent K/V base-pointer checks cover
  legal contiguous offset views; 32-half offsets remain aligned, one-half
  offsets take scalar fallback.
- K block loads require `slot>=0`; V block loads occur only inside the
  resident branch. Packed K/V still use their original lane unpackers and
  scale frames. K4V4 always retains scalar resident loading. Ragged rows exit
  before invalid page lookup, while partial valid pages still load allocated
  tiles and use the existing score mask. This does not establish robustness
  to NaNs in unused resident values.

Host enumeration performed here confirms identical address domains for
K64×64 and V32×64 versus scalar indexing: 12 slot/head combinations, each
covering 32,768 half elements. This checks address arithmetic, not compiled
CUTE lane permutations. The added GPU test covers both widths, splits
1/24/32, lengths 127/257/4001/4223, permuted pages/slots, five independently
aligned/unaligned K/V combinations, independent attention, exact fallback
parity and unchanged backing buffers.

and k09 `f26ef2323399ab410299db5c8caec41c8d63215a`. Frozen kernel upstream
