**Requirement and minimum change.** On Arc Pro B70/Xe2, D256/Q24/KV4 decode combines sixteen partial outputs and applies inverse H256 with fewer synchronizations. In `csrc/xpu/attn/xe_2/kvarn_decode.hpp`, k10 adds `KVarNReduceSplit16FourColumnOutputHadamardKernel` and selects it only for `unrotate_output && num_kv_splits == 16` in `KVarNDecodeD256G128DpasQ6PrefetchRecordCursorConfig::launch`: 139 additions/one deletion. Sixty-four threads each own four dimensions; explicit workgroup barriers decrease from ten to four, with subgroup LSE reduction. Shared storage stays 1088 bytes. Split accumulation order, inactive-split guards, both FP16 rounding boundaries, optional BF16 conversion and scratch layouts remain unchanged. The prior report's ownership analysis still applies; source inspection is not a device race proof, and positive valid sequence lengths remain a caller precondition.
