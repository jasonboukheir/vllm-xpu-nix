## Requirement and effective contribution

Qwen3.8-27B fresh GDN prefills on Xe2/Arc Pro B70 must not read another subgroup's
unfinished O2 workspace stores. The retained native tests use BF16 activations,
K16/V48 heads, D128, convolution width four, TP1 and 64-token chunks. They cover
fresh state, recycled state slots, ragged B4 versus B1, carried state and queued
asynchronous execution. This recurrent-layer requirement is independent of
KVarN target attention cache compression, the drafter's BF16 sliding attention
cache, images, and the chosen model runner.

The implementation delta is one `sycl::group_barrier(item.get_group())` in
`chunk_fwd_o_kernel`, immediately inside `if (!has_prev_state)` before the
fresh-state output GEMM. Apart from the explanatory comment and trailing
newline, that is the complete header delta. Later local commits do not change
the header. k04 adds a distinct mixed-decode regression to the same test file;
it neither repairs nor supersedes this barrier.
