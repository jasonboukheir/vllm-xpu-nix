## Minimal residual and sensitivity

Replace the caplog assertion with a scoped monkeypatch of `_fallback_varlen_attn` that fails immediately. Target wrapper lines 620–649 catch missing native configurations, warn only if the process-global `_warned_missing_configs` lacks that error, and invoke fallback regardless. Thus earlier tests can suppress every warning this commit checks.

Reuse `ref_paged_attn` for a finite, independent baseline check before repetitions, preferably with FP32 operands derived from the exact generated BF16 tensors. Preserve causal alignment, page mapping and existing justified tolerances; do not tune tolerances to make candidate errors pass. Repeatability against the first native result alone admits consistently wrong finite outputs. If the test continues to promise bitwise equality, compare integer/byte views: floating `torch.equal` equates signed zeros.

Retain the five cases and eight repetitions while consolidating duplicate setup in the existing attention suite where practical. No extra Cartesian matrix, V2/DFlash coverage or production fallback-policy change is warranted.
