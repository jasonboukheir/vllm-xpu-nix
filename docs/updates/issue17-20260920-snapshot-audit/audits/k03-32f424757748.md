## Released requirement

`causal_conv1d_non_spec` in `csrc/xpu/gdn_attn/gdn_attn_interface.cpp` must produce stable Q/K/V, gates and final convolution state for fresh Qwen prefills on Arc Pro B70, independent of recycled cache contents. The historical failure is corruption above the eight-token tiled threshold, not merely acceptable rounding differences between algorithms. Historical commit `1437161b97dfd7a6799ce2b2da5ab53fdcf36a6f` records corrupted Q/K/V and repeated `!` generation after the per-work-item metadata experiment `54d39759cdbd3ea16f9d4736af173cdfa5ba4c90`. Those historical explanations are reports, not a root cause independently proved by this audit.

k03 makes `enable_tiled_prefill=false`, so the Xe2 `num_prefills>0` branch uses `gdn::chunk_causal_conv1d_xe2` and fused L2 normalization. It leaves decode-only native dispatch, schemas and tensor layouts intact. Its 162-token BF16 regression uses 16 key heads, 48 value heads, D128, convolution width four, and a fresh state slot. Replaying with cache values 0, 3.25 and −1.75 must give bitwise-identical intermediates, z and final selected state. The test proves replay stability of the selected route; it does not compare against an independent convolution reference or force tiled dispatch.

At the full released kernel tip the guard and test are unchanged. Later mixed dispatch still sends its prefill subgroup through this function, so the requirement remains effective rather than superseded.
